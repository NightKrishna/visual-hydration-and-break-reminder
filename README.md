# Visual Hydration & Break Remind 💧👁️

> A clean, accessible web app for remote workers & students to prevent eye strain and dehydration.

**Human Need:** Eye strain, headaches, dehydration from long screen time.

**How it helps:** Enforces 20-20-20 rule (every 20 mins look 20ft away for 20 sec) + tracks 8 glasses water with visual milestones.

**Tech:** HTML, CSS, JS, setInterval, Notification API, localStorage - No backend needed.

**Accessibility:** Large fonts, high contrast, keyboard friendly.
